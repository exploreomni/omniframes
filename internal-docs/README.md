# Internal repository documentation

These specifications support development and maintenance of Omniframes. They live outside
`docs/` and are not included in the MkDocs site or its search index.

- [Bench dataset](BENCH_DATASET.md): generated tables, edge cases, and test invariants.
- [Bench Omni model](bench_omni_model.md): model definitions, warehouse setup, and fake API behavior.

See the [offline testing guide](../docs/offline-testing.md) for the test lanes and commands.
